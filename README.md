# Evolutive-Arquitecture

Constituição arquitetural evolutiva: diretrizes universais, verificáveis e versionadas para orientar decisões de arquitetura e engenharia.

## Estado atual

O projeto está em sua fase fundacional. A [Meta-Constituição](./META-CONSTITUTION.md) define como as futuras regras serão criadas, interpretadas, aplicadas e evoluídas.

Ainda não há regras arquiteturais universais publicadas.
